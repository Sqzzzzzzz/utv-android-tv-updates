# Обновления «Ю» для Android TV

Готовые APK доступны в [Releases](https://github.com/Sqzzzzzzz/utv-android-tv-updates/releases/latest). Для первого подключения автообновлений установите 0.6.0 поверх прежней версии, сохранив приложение и его данные.

Приложение проверяет `release.json` на главном экране не чаще раза в сутки. Загрузка начинается по кнопке «Обновить», установка — с подтверждением Android. Ручная проверка и переключатель автопроверки находятся в настройках.

Этот репозиторий содержит готовые подписанные APK и метаданные обновлений. Исходники и ключ подписи здесь не хранятся.

## Для публикации

Обновите `publication.json` после проверки и сборки новой версии прежним ключом. `parts` содержит SHA Git blobs частей готового APK в этом репозитории; сохраните их в отдельной ветке. Workflow проверяет размер, SHA-256, пакет, версию и сертификат APK, публикует выпуск, повторно скачивает и проверяет файл, затем обновляет `release.json`. Никогда не публикуйте APK, подписанный одноразовым ключом CI.

Файл `release.json` обновляется автоматически после успешной публикации. Старые опубликованные APK не перезаписываются; откат каталога на меньший номер версии запрещён.
